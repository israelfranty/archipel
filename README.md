# L'Archipel des Savoirs

Jeu d'apprentissage pour la 3e année du primaire (Québec) : maths, français et anglais.

**Jouer :** https://israelfranty.github.io/archipel/

- Trois îles : L'Île aux Nombres, L'Île aux Mots, English Island
- Niveaux adaptatifs, courses éclair, voix de lecture, compagnon animé
- Leçons « Les notions », atelier d'écriture au stylet, défis au tableau
- La progression est enregistrée sur l'appareil seulement (aucune donnée envoyée en ligne)
